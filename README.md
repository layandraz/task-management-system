\# Task Management System



A simple Java program that displays a to-do list. Each task has a title, a priority (High, Medium, or Low), and a completion status (Completed or Pending).



\## How to Run



1\. Make sure Java (JDK) is installed.

2\. Open a terminal in the project folder.

3\. Compile the program:

&#x20;  javac Task\_management\_system.java

4\. Run the program:

&#x20;  java Task\_management\_system
